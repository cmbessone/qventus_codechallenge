# Parts API

API de gestión de partes creada con FastAPI y SQLAlchemy.

## Instalación

Clonar el proyecto y luego:

```bash
poetry install
```

Run tests:
```bash
poetry run pytest
```

## Technology Stack

- FastAPI (Web Framework)

- SQLAlchemy (ORM)

- Pydantic (Validations)

- Pytest (Testing)

- Poetry (Dependency Manager)
